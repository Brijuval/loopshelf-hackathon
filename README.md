# LoopShelf

**Don't buy it. Loop it.**

LoopShelf is a hyperlocal, student-to-student micro-sharing network built for verified university campuses. It allows students to borrow everyday items (chargers, lab coats, calculators, cameras) for short durations instead of buying them.

## Live Demo
**[Try the Live Application Here!](https://main.d1v6kmiizdeazm.amplifyapp.com)**

## The Problem
College students constantly need expensive, single-use items for short periods. Buying these items is expensive and inefficient, yet campus communities lack a trust-verified platform to easily lend and borrow these idle items.

## Features
* **Demand Radar:** See exactly what items are trending and needed on campus.
* **Hyperlocal Tracking:** Distance-based logic shows you exactly where an item is.
* **Trust & Verification:** A built-in community review system ensures safe and reliable borrowing loops.
* **Responsive Design:** Optimized for both mobile devices and wide desktop displays.

## Tech Stack & AWS Deployment
This prototype was developed for the AWS **Zero to Shipped** Hackathon.
* **Frontend:** React, Vite, TailwindCSS, Framer Motion
* **Hosting:** AWS Amplify Hosting

## Run Locally
1. Clone the repository
2. Navigate to the prototype folder: cd prototype
3. Install dependencies: npm install
4. Run the development server: npm run dev
